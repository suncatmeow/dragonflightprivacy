Battle Mage: Dragonflight Privacy Policy

Developer: Suncat
Original draft date: October 10, 2026
Last reviewed: October 14, 2026

Scope of this draft

This draft describes the reviewed standalone HTML game, version 0.30.11. It does not establish the behavior of an Android wrapper or the version distributed through Google Play. The Android permissions, backup configuration, native libraries, network behavior, and correspondence with the released game remain unverified.

Information handled by the game

The reviewed HTML game saves preferences, best score, campaign checkpoints, and recent in-game upgrade offers locally using browser storage. Preferences include sound, graphics, controls, difficulty, and accessibility settings. Checkpoints contain game progress and character state so you can continue your adventure.

The reviewed HTML game does not require an account. No game-specific code that uploads saved progress, collects personal information or device identifiers, or integrates advertising, analytics, or remote crash reporting was identified. These findings apply to the inspected HTML source; they are not confirmation that the Android release contains no additional services.

Network communication and external services

The reviewed HTML includes its game engine and audio assets within the file. No game-specific network requests or remotely loaded assets were identified. Optional links in Suncat's studio lead to Suncat's music website and Instagram. Opening those links visits external websites with their own privacy practices.

This policy page is hosted on GitHub Pages. Visiting it is separate from playing the local game and is subject to GitHub's Privacy Statement.

Storage, backups, retention, and deletion

The reviewed game keeps its saved progress and preferences in local storage until that storage is cleared or replaced. For the browser version, use the browser's controls to clear the game's site data.

In an Android app, you can clear app storage through Android settings. Uninstalling removes local app storage. Android or your device provider may back up or transfer eligible app data, depending on the app's configuration, operating system, and device settings. Dragonflight's Android backup configuration has not yet been verified. Clearing local storage or uninstalling an app does not necessarily delete an existing backup, and a backup may restore data when the app is reinstalled or transferred.

Contact

For privacy questions or a request to delete information you have sent directly to Suncat, email suncat.data@gmail.com.

If you contact Suncat by email, your email address and the information you choose to include are received as support correspondence. Avoid including unnecessary sensitive information.

Updates

This draft must be reviewed against the Android release before it is finalized. Any later changes to the game's data handling must be reflected in this policy.
